# FreshMart Grocery Delivery System

CI6115 Programming III – Patterns and Algorithms, Coursework 2 (Kingston University / ESU).

A JavaFX desktop application in which customers register, browse and search groceries,
place delivery orders and receive invoices, and administrators manage products, stock and orders.

## Requirements
- JDK 21
- Maven 3.9+ (bundled with IntelliJ IDEA)

## Run
```
mvn clean javafx:run
```
